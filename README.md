The entry line:

> Out of office. Nobody watered me since March and I'm still alive, purely out of spite. Your email can wait too. - Fern

## Run it

```sh
python3 main.py
```

Writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then re-reads it to verify the bytes.
